# Перенос плагинов REAPER с Windows на Linux

## Главное

Сделать Windows-плагин «Linux-совместимым», изменив сам файл, нельзя: `.vst3` — это скомпилированные
64-битные Windows-библиотеки (PE/x86-64), исходного кода нет. Рабочих способов два:

1. **Нативная Linux-версия** от производителя, если она есть.
2. **Wine + [yabridge](https://github.com/robbert-vdh/yabridge)**: Windows-плагин запускается в Wine, а REAPER видит его
   как обычный Linux VST3. REAPER официально поддерживается yabridge.

## Разобранные плагины

| Файл | Производитель / версия | Что внутри | Linux-версия | Решение |
|---|---|---|---|---|
| `Speakers.vst3` | AudioThing, 1.2.3 | JUCE, своя лицензия (без iLok) | **Есть** (VST2/VST3/CLAP) | Скачать Linux-сборку в аккаунте [audiothing.net](https://www.audiothing.net/effects/speakers/), та же лицензия (до 3 компьютеров) |
| `Refire.vst3` | Outobugi (бесплатный, iPlug2) | Обычные системные DLL, без защиты | Нет («Linux: maybe», по словам автора) | **yabridge**, должен работать без проблем |
| `PitchMonster.vst3` | Devious Machines, 1.3.14 | JUCE, онлайн-активация через аккаунт | Нет (только Win/macOS) | **yabridge**, активация из окна плагина |

## Рекомендации

- **Ставьте плагины только официальными установщиками** внутри Wine-префикса и активируйте свою лицензию там же.
  Скрипт проверяет файлы и пропускает те, что были изменены после выпуска производителем: такой код непредсказуем,
  а в Wine у него есть доступ к домашней папке.
- **Плагины с защитой PACE/iLok в Wine не работают** — iLok License Manager под Wine не запускается
  (например, soothe от oeksound). Варианты:
  - оставить машину или раздел с Windows для таких задач;
  - взять нативные инструменты REAPER, они есть под Linux: **ReaFIR** (режим *Compress*) вместо резонансных
    подавителей, **ReaXcomp** — многополосный компрессор. Подходят и динамические эквалайзеры с Linux-сборками.
- Перед покупкой проверяйте на сайте производителя, нет ли Linux-версии (как у AudioThing) — она надёжнее моста.

## Установка на Linux

1. Установить REAPER **с reaper.fm** (не из Flatpak: yabridge с Flatpak не работает).
2. Установить **Wine Staging 9.21**: yabridge 5.1.1 не работает с Wine 9.22 и 10.x.
   На Ubuntu/Debian скрипт покажет команду установки и закрепления версии.
3. Скопировать папку с плагинами и `setup-yabridge.sh` на Linux и выполнить:

   ```bash
   chmod +x setup-yabridge.sh
   ./setup-yabridge.sh ~/plugins
   ```

   Скрипт поставит yabridge, создаст префикс `~/.wine-audio` и установит плагины из списка `ALLOWED`
   (**Refire** и **Pitch Monster**). Для **Speakers** он подскажет скачать нативную Linux-версию.
4. В REAPER: *Options → Preferences → Plug-ins → VST*. Проверить, что в путях есть `~/.vst3`, затем *Clear cache/re-scan*.

### Чтобы добавить другой лицензионный Windows-плагин

Запустите его официальный установщик в том же префиксе: `WINEPREFIX=~/.wine-audio wine Installer.exe`.
Затем выполните `yabridgectl sync`. Если копируете готовый `.vst3`, добавьте его имя в `ALLOWED` в скрипте.

### Советы по звуку на Linux

- Используйте PipeWire (с `pipewire-jack`) или JACK. В REAPER: *Audio device → JACK*.
- Добавьте пользователя в группу `audio` или `realtime` (зависит от дистрибутива) для работы в реальном времени.
- Отладка плагина: `YABRIDGE_DEBUG_FILE=/tmp/yabridge.log YABRIDGE_DEBUG_LEVEL=1 reaper`.

## Как проводился анализ

Разбор PE-заголовков (архитектура, секции, точка входа, таблица импорта), извлечение строк, проверка
цифровых подписей Authenticode, сверка со страницами производителей. Сами плагины не изменялись
и в репозиторий не входят.

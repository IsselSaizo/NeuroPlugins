# NeuroPlugins

Набор небольших программ и плагинов. Каждая папка — отдельный проект, подробности — в её README.

| Папка | Что это | Где работает |
|---|---|---|
| [DiskDoctor](DiskDoctor/README.md) | Анализ и очистка диска: что занимает место, что можно удалить, мусор и «хвосты» сломанных программ. Подсвечивает опасные места. Экспериментальная, проверена на одном ПК — используйте на свой страх и риск. | Windows 10/11, .NET 8 |
| [linux-migration](linux-migration/README.md) | «Мост» для VST3-плагинов REAPER на Linux: скрипт установки Wine + yabridge и разбор совместимости. Сами REAPER и плагины в репозиторий не входят. | Linux |
| [dsh-limit-guard](dsh-limit-guard/README.md) | Плагин для DeepSeek Harness: следит за лимитами подписки и контекста, у границы останавливает агента с записью handoff-файла и не даёт ему крутиться по кругу. Страница в настройках: сколько осталось и сколько % съела каждая задача. | DeepSeek Harness |

Все проекты распространяются под лицензией [GPL-3.0](LICENSE).
